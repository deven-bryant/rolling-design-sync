Rolling Design Sync

Scan a section or frame and sync it. The plugin hashes every node locally, compares against the hashes stored on the server, and uploads only changed or new nodes plus deletions. Instances are skipped, but every instance's main component is resolved and scanned into the server if missing (loading only the pages it lives on).
